
# RastaHale — Plataforma de Vídeos Mobile (Dados Mockados)

## Identidade Visual
- **Cores**: Gradiente laranja/pôr do sol (do pêssego ao laranja vibrante) + preto como cor de força
- **Logo**: Usar a logo do leão fornecida
- **Tipografia**: Bold e moderna, fundo escuro (dark theme) para remeter ao estilo Netflix
- **Border radius**: Arredondado para visual premium mobile

## Navegação (Bottom Tab Bar)
5 abas fixas no rodapé:
1. **Home** (ícone casa)
2. **Buscar** (ícone lupa)
3. **Favoritos** (ícone coração)
4. **Progresso** (ícone gráfico)
5. **Perfil** (ícone usuário)

## Telas

### 1. Home (Netflix-style)
- Banner hero com vídeo em destaque (imagem de fundo + botão play)
- Carrosséis horizontais por categoria:
  - "Continuar Assistindo"
  - "Jiu Jitsu — Fundamentos"
  - "Jiu Jitsu — Avançado"
  - "Surf — Técnicas"
  - "Luta Livre"
- Cada card mostra thumbnail, título e badge de nível (Iniciante/Intermediário/Avançado)

### 2. Buscar / Explorar
- Campo de busca no topo
- Filtros por: Categoria (Surf, Jiu Jitsu, Luta Livre), Nível, Duração
- Grid de resultados com thumbnails

### 3. Tela de Detalhes do Vídeo
- Player de vídeo mockado (thumbnail com botão play)
- Título, instrutor, duração, nível
- Descrição da técnica
- Botões: Favoritar, Marcar como assistido
- Seção "Vídeos Relacionados"

### 4. Favoritos
- Lista dos vídeos favoritados pelo usuário
- Cards com thumbnail, título e opção de remover

### 5. Progresso
- Estatísticas mockadas: total de aulas assistidas, horas de treino, sequência de dias
- Lista de aulas com barra de progresso individual
- Badges de conquista (ex: "10 aulas concluídas", "Primeira aula de Surf")

### 6. Perfil
- Avatar, nome e plano do usuário (mockado)
- Opções: Editar Perfil, Meu Plano, Configurações, Sair

## Dados Mockados
- ~15 vídeos distribuídos entre Jiu Jitsu, Surf e Luta Livre
- 3 instrutores fictícios
- Progresso parcial simulado

## Aspectos Técnicos
- Design mobile-first (max-width ~430px centrado)
- Dark theme como padrão
- Animações suaves nos carrosséis
- Viewport otimizado para mobile
